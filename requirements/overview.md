# Notifyx — Project Overview

A multi-tenant distributed notification service that supports Email, Push, SMS, and In-app (WebSocket) channels via an event-driven pipeline.

## Goals
- Showcase distributed systems, event-driven architecture, and multi-tenancy
- Use entirely free-tier services (no paid infrastructure)
- Deployable on Render with local dev via Docker Compose
- Portfolio-grade: production patterns (DLQ, retry, rate limiting, deduplication, observability)
